# Agency Contractor 0.1.77 — стабільний реліз

## Сканування документів
- Кнопка «Сканувати…» у профілі працівника для власних підписаних документів.
- Багатосторінкове сканування, імпорт з файлу, редактор сторінок, збереження одного PDF або JPG.
- Підтримка WIA і TWAIN; резервні варіанти через Windows Scan.

## Сканер (WIA)
- Усі типи підключення сканера (крім камери).
- Стабільне закриття вікна під час сканування.
- Дедуплікація одного фізичного пристрою в списку (HP / Agro Personal).

## Multi-PC і сповіщення
- SyncEvents Inbox/Read: автоматичне видалення файлів старше 24 годин.
- Дзвіночок сповіщень: записи старше 24 годин прибираються автоматично.
- Старі sync-події (>2 год) оновлюють екрани без зайвих спливаючих toast.

## З попередніх версій (0.1.74–0.1.76)
- PostgreSQL multi-PC, LISTEN/NOTIFY, підключення другого ПК.
- Захист зарплат при роботі з кількох ПК, row-level upsert, точніші sync-події.
- Автоочищення дублікатів salary history, PostgresConnectionFactory, workspace passport.

## Документи
- Виправлено превʼю PDF візи в картці працівника.

## Автооновлення
- Стабільний реліз `0.1.77` для каналу **stable** (GitHub Releases + Velopack).
- Завантажте `AgencyContractor-win-Setup.exe` або оновіться через Налаштування → Оновлення.

## Що тестувати
- Сканування → збереження в профіль працівника.
- 3–4 ПК: менше файлів у SyncEvents, менше шуму в дзвіночку.
- PostgreSQL: зарплати, sync, другий ПК.
- Автооновлення з 0.1.73 / 0.1.76 (stable-канал).
