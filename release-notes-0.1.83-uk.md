# Agency Contractor 0.1.83 — стабільний реліз

## Фінанси — стабільність даних
- Виправлено зникнення працівника з історичних місяців зарплати після сценарію: фірма A → архів → фірма B → архів.
- Збережені зарплатні рядки більше не втрачаються при перерахунку, якщо період роботи не знайдено, але дані вже були введені.
- На картці працівника з Фінансів під датою наступу показується **дата закінчення роботи в цій фірмі** (коректно для кількох фірм і повторного найму).

## Звіт
- Повні дані працівника (віза, орган тощо) для минулих фірм у сценарії з архівом і переведенням між фірмами.

## Експорт зарплати в Excel
- Групування фірм **по агенціях**: розгортання, чекбокс на всю агенцію, чекбокси окремих фірм.
- Пошук агенції або фірми для швидкого вибору.
- Виправлено дублювання однакових агенцій (різні пробіли/регістр у назві).

## Автооновлення
- Стабільний реліз `0.1.83` для каналу **stable** (GitHub Releases + Velopack).
- Оновлення: **Налаштування → Оновлення** або `AgencyContractor-win-Setup.exe`.

## Що тестувати
- Фінанси: працівник з кількома фірмами в історії — рядки в минулих місяцях на місці.
- Відкрити картку з Фінансів — дата закінчення в потрібній фірмі.
- Експорт Excel: групи агенцій, пошук, вибір частини фірм.
- Звіт: повні поля для минулої фірми після архіву.
