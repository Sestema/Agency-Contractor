# Agency Contractor 0.1.95 — фінанси: швидкість і стабільність UI

## Зарплата — введення годин (слабкі ПК / iGPU)
- Один перерахунок підсумків на коміт комірки замість потрійного каскаду.
- Equality guards: Enter без змін більше не ганяє перерахунки.
- Картки фірм справа оновлюються на місці (без повного перестворення панелі).
- Прибрано постійну DropShadow з правої панелі — менше навантаження на рендер.
- Ставка (HourlyRate) комітується по LostFocus, як години.

## Зарплата — Save і multi-PC без зависання UI
- Очікування shared-lock більше не блокує UI через Thread.Sleep (async Acquire).
- Save / Upsert / SaveFirmPayments працюють через async API.
- Додавання, зміна та видалення витрат — async-лок.
- «Оплатити всіх» / зняти оплату: запис історії у фоні, потім один Save.
- Одиночний чекбокс «оплачено»: історія у Task.Run.

## Зарплата — UX
- Пігулка вибраної фірми: ✕ завжди видно; довга назва обрізається з «…».
- Статус «Збереження…» з локалізацією uk/en/ru/cs; безпечний пошук рядків (TryFindResource).
