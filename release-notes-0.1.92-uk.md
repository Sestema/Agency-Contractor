# Agency Contractor 0.1.92 — виправлення критичного бага

## Акаунт / профіль
- Виправлено критичний баг: після оновлення з `0.1.90` на `0.1.91` програма іноді просила створити новий акаунт замість входу в існуючий, хоча ПК не змінювався.
- Причина: ідентифікатор ПК (`machine_id`) обчислювався на основі даних WMI (диск/процесор), і при тимчасовому збої цього механізму після оновлення отримувалося інше значення, яке сервер сприймав як новий ПК.
- Фікс: `machine_id` тепер один раз обчислюється і зберігається у налаштуваннях програми. Усі наступні запуски (включно з майбутніми оновленнями) використовують це збережене значення, навіть якщо WMI тимчасово недоступний. Додано також резервне джерело (реєстр Windows), яке не залежить від WMI.
