# Agency Contractor 0.1.79 — стабільний реліз

## PDF редактор (режим «Накладання»)
- Рамка тега під обраний шрифт і розмір (pt) — точніше позиціонування на шаблоні.
- Згенерований текст з’являється там, де поставили рамку (WYSIWYG): спільний малюнок через `PdfTextLayoutHelper`, вирівнювання зверху.
- Поля шаблону: текст у PDF з верхнього краю прямокутника (не по центру).

## Зарплати (SQLite і PostgreSQL)
- Список доступних місяців зарплат через `GetAvailableMonths()` — коректно в PostgreSQL і SQLite.
- Стрілка «наступний місяць» оновлюється миттєво при перемиканні; підхоплює місяці, створені на іншому ПК.

## З попередньої версії 0.1.78
- Заміна документів HEIC/PDF, підсвітка номера страховки, збереження одного рядка зарплат (аванси), сплеш, бекапи, multi-PC sync 24 год.

## Автооновлення
- Стабільний реліз `0.1.79` для каналу **stable** (GitHub Releases + Velopack).
- Оновлення: Налаштування → Оновлення або `AgencyContractor-win-Setup.exe`.

## Що тестувати
- PDF шаблон: теги на лініях форми → генерація для працівника — текст на тому ж місці.
- Зарплати: перемикання місяців, стрілка вперед/назад, другий ПК з новим місяцем.
