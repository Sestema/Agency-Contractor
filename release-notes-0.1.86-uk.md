# Agency Contractor 0.1.86 — стабільний реліз

## Працівники
- Оновлені кнопки документів на плитках: іконки, кольори за терміном дії, layout 3 або 4 в ряд; клік відкриває файл, клік по картці — профіль.
- Логічний зум плиток — чіткіший текст і фото без розмиття при зміні масштабу.
- Ім'я та прізвище окремими рядками на плитках; адаптивна ширина карток (х1–х6).
- Покращена верхня панель: пошук, статистика, сортування; стан «нічого не знайдено» і «Скинути фільтри».

## Головне меню
- Віджет погоди: температура та іконка за поточною локацією.

## Проблеми
- Новий вигляд рядків — без «червоної стіни», кольорова смуга серйозності зліва.
- Іконки типів документів (паспорт, віза, страховка, дозвіл) замість однакового попередження.
- Пошук і фільтр по фірмі; порожній результат з кнопкою скидання фільтрів.

## Архів
- Фільтр по фірмі; дата «В архіві» на картці.
- Нейтральний чип фірми (не оранжевий «попередження»).
- Прибрано довгий шлях до папки з картки; повний шлях — у кнопці «Папка».
- Чіткіший текст карток; зум без розмиття.

## Профіль працівника
- Спокійніший сайдбар (без «веселки» кнопок); підписи та tooltip до дат.
- Кольорова рамка статусу на картках документів; попередження про термін дозволу на роботу.
- Виправлено заміну дозволу на роботу: новий файл зберігається, старий переноситься в CustomDocs.

## Налаштування
- Бічна навігація (Програма / Сервери / Користувачі); сітка тем 4×2.

## Стабільність
- Виправлено помилку при закритті програми (фонові перевірки після shutdown).

## Автооновлення
- Стабільний реліз `0.1.86` для каналу **stable** (GitHub Releases + Velopack).
- Оновлення: **Налаштування → Оновлення** або перевстановлення через `AgencyContractor-win-Setup.exe`.

## Що тестувати
- Працівники → плитки: документи, зум, пошук, х1–х6.
- Проблеми: фільтри, новий вигляд рядків.
- Архів: фільтр по фірмі, дата архівації, відновлення.
- Профіль → заміна дозволу на роботу (файл + CustomDocs).
- Оновлення з 0.1.85 → 0.1.86.
