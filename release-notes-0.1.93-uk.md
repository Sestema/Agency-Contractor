# Agency Contractor 0.1.93 — продуктивність і виправлення UI

## Продуктивність
- Головне меню: асинхронне завантаження списку фірм і підрахунків у хедері — менше підвисань при відкритті панелі вибору фірми.
- Головне меню: вибрана фірма зберігається при переході між модулями (наприклад, «Працівники» → назад).
- Головне меню: прибрано тіні з плиток меню (12 карток) — менше навантаження на відеокарту.
- Працівники, кандидати, архів, шаблони, проблеми: прибрано тіні з карток у списках і плитках.
- Працівники: зменшено розмір декодування фото в режимі «Плитки» (512 → 200 px) — менше RAM і GPU.

## UI / теми
- Виправлено видимість погоди та дати в темних темах (раніше світлий текст на світлому фоні).

- Стабільний реліз `0.1.93` для каналу **win** (GitHub Releases + Velopack).
