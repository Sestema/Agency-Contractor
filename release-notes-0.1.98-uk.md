# Agency Contractor 0.1.98 — швидший список і зручніший профіль

## Пакет документів
- Режим **Редагувати / Зберегти / Скасувати** — зміни чекбоксів і приміток зберігаються однією дією.
- У примітках знову можна ставити **пробіл** (більше не обрізається під час друку).
- Прибрано велику зелену рамку заголовка — лишилися лише надписи.

## Працівники — швидкість і скрол
- Список фірми більше не читає `employee.json` лише заради статі (стать у профілі без змін).
- Кеш списку (~10 с) також для шляху UI — повторне відкриття фірми швидше.
- Прибрано зовнішній ScrollViewer: таблиця й список краще віртуалізуються; усі працівники як і раніше завантажуються повністю.
- Фото на картці трохи вище (портретний формат), щоб краще влазило обличчя.

## Адреса виконання роботи
- При **Редагувати** адреса більше не «зникає», якщо формат у файлі трохи відрізняється від списку фірми.
- Wizard і профіль пишуть адресу однаковим форматом; якщо адреси немає в списку фірми — показується збережене значення.

## Автооновлення
- Стабільний реліз `0.1.98` для каналу **win** (GitHub Releases + Velopack).
- Оновлення: **Налаштування → Оновлення** або `AgencyContractor-win-Setup.exe`.
