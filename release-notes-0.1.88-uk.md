# Agency Contractor 0.1.88 — стабільний реліз

## Фінанси — перейменування фірми
- Виправлено зникнення годин після перейменування компанії (наприклад `Holz Schiller s.r.o. (Klatovy)` → `Holz Schiller s.r.o.`).
- При rename мігруються salary DB, шляхи папок, індекс працівників і історія назв (`NameHistory`).
- Автоматичне відновлення старих alias-назв при старті програми (repair).
- Фінанси коректно показують години під поточною назвою без ручного відкочування імені.

## Автооновлення
- Стабільний реліз `0.1.88` для каналу **win** (GitHub Releases + Velopack).
- Оновлення: **Налаштування → Оновлення** або `AgencyContractor-win-Setup.exe`.

## Що тестувати
- Перейменувати фірму → відкрити фінанси за попередні місяці — години на місці.
- Оновлення з 0.1.87 → 0.1.88 через Налаштування.
