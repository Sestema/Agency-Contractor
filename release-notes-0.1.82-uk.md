# Agency Contractor 0.1.82 — стабільний реліз

## Фінанси
- Шапка фірми та таблиця зарплат виглядають як один блок: назва, іконка та кількість працівників по центру.
- Оновлена верхня панель підсумків (компактніші метрики).
- М’якші розділювачі ширини колонок у заголовку таблиці — функція зміни ширини збережена.

## Проблеми
- Компактніші картки: менше відступів, менші аватари та шрифти — зручніше переглядати довгі списки.

## Продуктивність і UI
- Прибрано масштабування карток при наведенні у вкладках **Працівники**, **Кандидати**, **Архів**, **Проблеми**.
- Текст на наведеній картці залишається чітким; підняття та тінь при hover збережені.
- Менше навантаження на слабких ПК при прокрутці списків карток.

## Внутрішні зміни
- Модульна реєстрація сервісів (DI) — легше підтримувати код, поведінка програми для користувача не змінилась.

## З попередньої версії 0.1.81
- Тема Agency Teal, drawer «Фірми» з пошуком і сортуванням, оновлені плитки працівників.

## Автооновлення
- Стабільний реліз `0.1.82` для каналу **stable** (GitHub Releases + Velopack).
- Оновлення: **Налаштування → Оновлення** або `AgencyContractor-win-Setup.exe`.

## Що тестувати
- Фінанси: блок фірми + таблиця, зміна ширини колонок, верхня панель підсумків.
- Проблеми: компактні картки, відкриття профілю.
- Працівники / Кандидати / Архів: hover на картках — текст не розмитий, без підвисань.
