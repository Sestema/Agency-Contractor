# Agency Contractor 0.1.87 — стабільний реліз

## Працівники
- Нова верхня панель: брендинг, пігулка фірми з dropdown-перемиканням, пошук, Excel / AI / Вибір / Додати.
- Другий ряд: статистика (Всього / Проблеми / Нових), сортування, режими перегляду, зум.
- Покращена чіткість тексту при масштабуванні інтерфейсу.
- Пакетна AI-обробка та пакетна генерація документів для працівників.

## Головне меню
- Нова компактна верхня панель: фірма зі статусом, картки «Проблеми» і «Працівники», погода, привітання з датою, годинник з UTC.
- Прибрано кольорову смужку зверху картки.

## Звіт — інтерфейс та аналітика

### Фільтри
- Фільтри перенесено в ліву бокову панель (роботодавці, агентства, період).
- Пошук по фірмах і агентствах, тристанний «вибрати все» для чекбоксів.
- Період через чернеткові дати — застосування кнопкою «Показати».
- Виправлено прокрутку коліщатком над текстом у фільтрах.

### Заголовок звіту
- Перемикач «Зведення» / «Працівники» відцентровано в шапці.

### Картки показників (зведення)
- 6 компактних карток в один ряд з горизонтальною прокруткою на вузьких екранах.
- Оновлені підписи та метрики: працювало за період, активні, рух, без дозволу, документи, агентства.

### Оверлей «Рух за період»
- Клік по картці відкриває деталізацію: прийняті та звільнені за обраний період.
- Клік по працівнику в списку відкриває його картку.

### Оверлей «Без дозволу»
- Деталізація у двох колонках: активні без дозволу / звільнені за період.
- Лічильник на картці узгоджено з вмістом оверлею.
- Виправлено порожній оверлей при непорожній картці — тип визначається за кодом `passport_only`, а не за перекладеною назвою.

### Виправлення помилок
- Усунено збій при відкритті дашборду/звіту (відсутній ресурс `DashboardWidgetCard`).
- Дашборд з вбудованим оверлеєм руху; спільні оверлеї — лише у звіті.

## Локалізація
- Нові рядки для звіту, оверлеїв, панелей Працівників і Головного меню у **uk / en / ru / cs**.
