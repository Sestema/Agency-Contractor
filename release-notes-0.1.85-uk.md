# Agency Contractor 0.1.85 — стабільний реліз

## Працівники — картки та документи
- Оновлені кнопки документів (паспорт, віза, страховка, дозвіл): іконки, пастельні кольори за терміном дії, адаптивний layout (3 або 4 кнопки в ряд).
- Клік по кнопці документа відкриває файл; клік по картці — профіль працівника.
- Іконки відцентровані в кольорових плитках; виправлено обрізання «Страховка» в layout 4-в-ряд.
- Покращена верхня панель: центрування пошуку, іконки та hover на статистиці, єдиний блок сортування.

## Налаштування
- Бічна навігація (Програма / Сервери / Користувачі) замість горизонтальних вкладок.
- Сітка тем 4×2 замість 3+3+2.

## Автооновлення
- Стабільний реліз `0.1.85` для каналу **stable** (GitHub Releases + Velopack).
- Оновлення: **Налаштування → Оновлення** або `AgencyContractor-win-Setup.exe`.

## Що тестувати
- Працівники → плитки: документи, кольори, клік по файлу.
- Налаштування → бічна панель і вибір теми.
- Автооновлення з 0.1.84 → 0.1.85.
