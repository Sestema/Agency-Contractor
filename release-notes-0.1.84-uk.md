# Agency Contractor 0.1.84 — стабільний реліз

## Працівники — адаптація карток під розмір тексту
- Виправлено накладання та обрізання прізвища на картці плитки при великому «Розмірі тексту» або на деяких розширеннях монітора.
- Ширина картки плитки тепер **масштабується разом із текстом** (`UiEmployeeTileW`) — довгі прізвища вміщаються без зайвого переносу на один символ.
- Висота картки підлаштовується під вміст (ім'я, посада, фірма) замість жорстких піксельних обмежень на імені.

## Автооновлення
- Стабільний реліз `0.1.84` для каналу **stable** (GitHub Releases + Velopack).
- Оновлення: **Налаштування → Оновлення** або `AgencyContractor-win-Setup.exe`.

## Що тестувати
- Працівники → плитки: «Розмір тексту» = ExtraLarge — довге прізвище не накладається на посаду.
- Те саме з «Розмір інтерфейсу» = Large/ExtraLarge.
- На звичайному (Medium) вигляд карток лишився як раніше.
