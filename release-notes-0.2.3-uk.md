# Agency Contractor 0.2.3 — підписані документи та анкета PDF

## Підписані документи
- Редагування назви або дати підпису також перейменовує файл у `CustomDocs`.
- Компактні картки, редагування назви/дат, рамка секції як у паспорта й візи.
- Після архіву документи лишаються під старою фірмою; у профілі — групи «поточна / попередні».
- У Проблемах для кастомних документів: **Завершити дійсність** (файл лишається, з проблем зникає). У профілі — бейдж і **Відновити дійсність**. Паспорт / віза / страховка / дозвіл без змін.

## Анкета PDF
- Більші фото й текст, дві колонки на одній сторінці.
- Шапка: фото, ім’я, фірма, тип договору; посада лише в блоці роботи.
- Рамка лише навколо фото, без порожньої смуги вниз.

## Стабільність
- Виправлено падіння профілю через ресурс картки документів.
- Діалог пакета документів: віртуалізація списку, Esc закриває вікно, спочатку повні пакети.
