# Agency Contractor 0.1.96 — зарплата та сканування документів

## Зарплата — фіксована місячна сума
- Якщо **ставка = 0**, колонку «Нараховано» можна ввести вручну (фіксована зарплата за місяць).
- Години можна вести окремо для обліку; підсумки, нетто, Excel/PDF беруть ручну суму.
- Значення зберігається в поточному місяці (без зміни схеми БД); на наступний місяць **не** копіюється.
- При ставці > 0 поведінка як раніше: години × ставка.

## Зарплата — попап авансу
- Іконка закриття — ✕, видалення — червона корзина (замість порожніх квадратів).

## Профіль працівника — сканування документів
- Виправлено «Готово» після скану: вікно більше не блокується повідомленням «зачекайте, доки документ збережеться».
- Відсканований файл коректно повертається в діалог додавання документа.

## Автооновлення
- Стабільний реліз `0.1.96` для каналу **win** (GitHub Releases + Velopack).
- Оновлення: **Налаштування → Оновлення** або `AgencyContractor-win-Setup.exe`.
