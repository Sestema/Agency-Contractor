# Agency Contractor 0.2.0 — кошик і фінанси

## Недавно видалені ↔ фінанси
- Працівник у кошику **не показується** у зарплаті за місяць (без червоних «мертвих» рядків).
- Дані в `salary_*.db` / Postgres **зберігаються**, поки людина в кошику.
- **Зберегти** у фінансах не стирає ці рядки (merge при replace-сейві).
- **Відновити** з кошика — знову видно у фінансах з тими ж годинами, ставкою й авансами; шляхи папок підтягуються.
- **Видалити назавжди** або автоочистка кошика (~30 днів) — повністю прибирає salary entries, історію зарплати та пов’язані фінанси.

## Дрібні UX
- Dashboard «Рух за місяць»: коректний роздільник дат.
- Wizard додавання працівника: стабільніші дати в DatePicker.
- Список працівників: чіп «Пакет док.» у тому ж стилі, що «Всього».
