# Agency Contractor 0.1.97 — пакет документів і стабільніший індекс

## Пакет документів (нова фіча)
- У картці фірми — вкладка **«Пакет документів»**: список обов’язкових документів (назва + відстеження **Наявність** / **Насканований**).
- У профілі працівника — вкладка **«Пакет документів»**: чекбокси та примітка по поточній фірмі.
- Статуси зберігаються в `employee.json` і **не губляться**, якщо змінили фірму або прибрали документ з пакета.
- Прибраний з пакета документ потрапляє в **soft-archive** (тільки перегляд); попередні фірми — read-only історія.
- На списку працівників — віджет **«Пакет док.»** з % виконання; діалог по людях; клік по імені відкриває профіль на вкладці пакета.
- Зміни шаблонів / чекбоксів / приміток пишуться в історію працівника та activity log.
- Локалізація: uk / cs / en / ru.

## Індекс працівників (швидкість і multi-PC / OneDrive)
- При розбіжності індексу зі списком папок більше **немає глобального** `DELETE` усього `employee_index`.
- Repair лише **цієї фірми** (Upsert); на hot-path orphans не видаляються, щоб недокачаний OneDrive не «з’їв» людей з індексу.
- Перевірка «рядки vs папки» — **раз на фірму за сесію**, а не на кожне відкриття списку.
- Фонова session integrity на старті лишається; повний rebuild — лише для порожнього індексу / ручного сценарію.

## Сканування документів
- WIA silent scan більше не морозить UI (окремий STA-потік + таймаут).
- Для eSCL/мережевих сканерів (наприклад Agro Personal) одразу відкривається діалог Windows.
- При таймауті — fallback на WIA CommonDialog.
