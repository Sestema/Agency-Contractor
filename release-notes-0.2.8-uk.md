# Agency Contractor 0.2.8 — працівники, архів і PDF-поля без Java

## Працівники
- Шапка зі статистикою, сортування, режими перегляду з плавним перемикачем і масштаб.
- Таблиця щільніша: дати документів видно чіпами.

## Архів
- Така сама шапка: пошук, фільтри «Усі», «Цей місяць» і «Без фото».
- Сортування за ім’ям, датою завершення і фірмою.
- Картки масштабуються. Режими: список, плитки й значки.

## PDF-шаблони з полями
- Java більше не потрібна, і програма не закривається приблизно через хвилину після бланка.
- Текст пишеться прямо в поле. Чеські літери зберігаються.
- Списки, як Pohlaví (Muž, Žena, Jiné), освіта і медична страхова, обирають готовий пункт. Слова в списку лишаються словами.
- Один і той самий файл програми працює без окремого ключа на кожен комп’ютер.

## Автооновлення
- Стабільний реліз `0.2.8` для каналу **win** (GitHub Releases + Velopack).
- Оновлення: **Налаштування → Оновлення** або `AgencyContractor-win-Setup.exe`.
