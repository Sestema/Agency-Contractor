# Agency Contractor 0.1.89 — стабільний реліз

## Фінанси — надійність
- Виправлено небезпечне зіставлення шляхів папок через SQL LIKE (символ `_` у назвах фірм).
- Точніше оновлення шляхів при repair/rename — менше ризику зникнення годин після перейменування компанії.

## Фінанси — налаштування відображення
- Нова шестірня у верхній панелі: **«Налаштування відображення»**.
- **Порядок імені:** Ім'я Прізвище / Прізвище Ім'я — для таблиці та Excel.
- **Формат годин:** округлено до 1 знака або довільна точність (наприклад 213,23).
- Сортування по колонці імені відповідає обраному порядку відображення.

## Архів
- Кнопка **«Видалити»** у профілі архівного працівника — та сама логіка, що у вкладці «Працівник» (пароль → «Недавно видалені»).

## Автооновлення
- Стабільний реліз `0.1.89` для каналу **stable** (GitHub Releases + Velopack).
- Оновлення: **Налаштування → Оновлення** або `AgencyContractor-stable-Setup.exe`.

## Що тестувати
- Фінанси: перейменування фірми → години на місці; налаштування імені та формату годин.
- Архів: відкрити профіль → Видалити → працівник зникає з архіву, з'являється в «Недавно видалені».
- Оновлення з 0.1.88 → 0.1.89 через Налаштування.
